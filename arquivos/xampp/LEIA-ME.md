# arquivos\xampp (opcional)

Cópia da pasta `C:\xampp` de um XAMPP **recém-instalado**, da **mesma versão** do instalador em `softwares\laboratorio`.

Dela saem a `htdocs` e os bancos (`mysql\data`) padrão, para os quais os PCs dos labs voltam. A versão é lida do `readme_en.txt`.

Esta pasta não é copiada para o PC: só o que o script precisa.
